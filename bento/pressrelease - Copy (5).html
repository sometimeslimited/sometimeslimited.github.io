Description

Bento Blocks is a cozy, puzzly cooking game about making bento lunch boxes. Slice ingredients, rearrange them, and fit them into each box using the fewest cuts possible.

Key Information

Over 180+ quirky levels. No pressure, no timer. Hand-painted art and a relaxing soundtrack.
